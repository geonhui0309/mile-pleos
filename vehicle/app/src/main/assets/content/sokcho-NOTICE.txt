Driving timing prototype (2026-10-25)
Driving_route.json and driving_context.geojson derive from the same one-off OSM
extract above; the route file name is driving_route.json (lowercase).
The context contains only geometry and map labels, not contributor identities.
Assumed announcement windows and synthetic position errors are test parameters,
not measured roadside visibility or a calibrated GNSS error model.

3D scene prototype (2026-10-25)
terrain_3d_data.json contains a native-grid crop of the same Copernicus DSM and
OSM building footprints / tree point locations from the same extract above.
OSM building heights, tree heights and crowns are unmeasured assumptions.
Synthetic building/tree positions are test-only, not observations.
DSM samples are rendered as planar triangles, not a detailed surveyed rock model.
